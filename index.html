pfsense-abuseipdb

FreeBSD pkg repository for pfSense-pkg-abuseipdb - Suricata eve.json watcher reporting to AbuseIPDB, abusix X-ARF and MySQL, with pfSense UI status and settings pages.

On the pfSense host, add this repo and install:

cat > /usr/local/etc/pkg/repos/pfsense-abuseipdb.conf <<'EOF'
FreeBSD: { enabled: no }

pfsense-abuseipdb: {
  url: "https://tmiland.github.io/pfsense-abuseipdb/repo",
  mirror_type: "http",
  signature_type: "none",
  enabled: yes
}
EOF
pkg update
pkg install -r pfsense-abuseipdb pfSense-pkg-abuseipdb

Project sources: github.com/tmiland/pfsense-abuseipdb
