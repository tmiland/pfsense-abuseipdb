pfsense-abuseipdb

FreeBSD pkg repository for pfSense-pkg-abuseipdb - DDoS protection (native pf or Suricata) + AbuseIPDB/abusix X-ARF abuse reporting with MySQL logging and a native pfSense web UI.

On the pfSense host, add this repo and install:

cat > /usr/local/etc/pkg/repos/pfsense-abuseipdb.conf <<'EOF'
FreeBSD: { enabled: no }

pfsense-abuseipdb: {
  url: "https://tmiland.github.io/pfsense-abuseipdb/repo",
  mirror_type: "http",
  signature_type: "none",
  enabled: yes
}
EOF
pkg update
pkg install -r pfsense-abuseipdb pfSense-pkg-abuseipdb

Project sources: github.com/tmiland/pfsense-abuseipdb — built with opencode.
